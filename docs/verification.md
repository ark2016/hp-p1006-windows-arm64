# Проверка работы

Состояние на **15 ноября 2026 года**. Ниже — обезличенная сводка локальных отчётов и подтверждений владельца принтера.

Проверенная конфигурация:

- Ноутбук ASUS Zenbook A14 **UX3407QA**.
- Процессор **Qualcomm Snapdragon X X1-26-100**; системная строка: `Snapdragon(R) X - X126100 - Qualcomm(R) Oryon(TM) CPU`.
- **Windows 11 ARM64, 25H2**, сборка **26200.9974**.
- **HP LaserJet P1006**, подключённый по USB: `VID_03F0`, `PID_3E17`.
- Очередь Windows использует **Microsoft IPP Class Driver** и локальный мост.

| Сценарий | Подтверждённый результат | Граница проверки |
| --- | --- | --- |
| Печать из Microsoft Word | Владелец подтвердил корректную печать первых двух страниц задания из пяти. | Остальные страницы были остановлены выключением принтера; всё задание целиком не проверено. |
| Печать после выключения и включения принтера | Прошивка снова готова; отдельное задание вывело один лист. Владелец подтвердил читаемость русского и английского текста. | Это проверка включения принтера, а не перезагрузки Windows. |
| Диалог печати Chrome | HP виден в полном списке принтеров через «Ещё…»; предпросмотр работает, кнопка печати активна. | Физическая печать из Chrome не подтверждена. |
| Автозапуск моста | Установка для обычного пользователя выполнена; ярлык проверен, мост отвечает. Отдельно проверены скрытый запуск через `pythonw` и повторный запуск без вмешательства в работающий экземпляр и его задания. | Запуск после фактического выхода и повторного входа в Windows пока не проверен. |

**Программные проверки:** 15 ноября локально прошли **55 тестов**, без ошибок, падений и пропусков. Набор охватывал преобразование документов, настоящий рендеринг PDF средствами Windows, HTTP/IPP на локальном интерфейсе и защиту от повторного запуска. USB-передача в этих проверках заменена имитацией; отдельно допускалось только чтение сведений об устройстве. Физическая печать подтверждена приведёнными выше пользовательскими проверками, а не результатом тестового набора.

Другие модели принтеров, компьютеры и версии Windows не проверялись. Серийные номера, UUID, имена пользователей, локальные пути и содержимое напечатанных документов в эту сводку не включены.
