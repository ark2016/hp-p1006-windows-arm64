# HP LaserJet P1006 на Windows 11 ARM64

Пользовательский мост, позволяющий печатать на **HP LaserJet P1006** (USB) с
компьютеров на **Windows 11 ARM64**, для которых HP не выпускает драйвер.

*A user-mode IPP bridge that lets Windows 11 on Arm print to an HP LaserJet
P1006 over USB through the inbox Microsoft IPP Class Driver and usbprint.sys.*

Это **не** подписанный пакет драйвера ARM64 (DLL/INF) и не драйвер ядра.
Системные драйверы не заменяются, установщик HP не запускается.

## Проверенное оборудование

| Компонент | Значение |
| --- | --- |
| Компьютер | ASUS Zenbook A14 UX3407QA |
| Процессор | Qualcomm Snapdragon X X1-26-100 (ARM64) |
| ОС | Windows 11 25H2, сборка 26200.9974 |
| Принтер | HP LaserJet P1006, USB `VID_03F0` / `PID_3E17` |
| Очередь Windows | Microsoft IPP Class Driver |

Другие модели принтеров, компьютеры и версии Windows не проверялись.
Результаты проверок и их границы — в [docs/verification.md](docs/verification.md).

## Архитектура

```text
приложение (Word, Chrome, …)
  → Microsoft IPP Class Driver (штатная очередь Windows)
  → локальный IPP-сервер http://127.0.0.1:8631/ipp/print   (p1006, Python)
  → PDF (Windows.Data.Pdf) / PWG Raster → монохромный растр A4
  → foo2xqx + JBIG → поток XQX 1200×600
  → штатный usbprint.sys → HP LaserJet P1006
```

- Сервер слушает только `127.0.0.1`; внешние сервисы не используются.
- P1006 хранит firmware только в ОЗУ. Мост сам загружает runtime firmware
  после каждого включения принтера (это не перепрошивка постоянной памяти).
- Python и конвертеры собираются как x64-приложения и на ARM64 выполняются
  через штатную эмуляцию Windows.

## Зависимости

- **Python 3.10+** (проверено на 3.13) с **Pillow** из `requirements.txt`.
- **7-Zip** (по умолчанию `C:\Program Files\7-Zip\7z.exe`).
- **MinGW-w64 GCC** (по умолчанию `C:\Strawberry\c\bin\gcc.exe`).
- Установщик HP **`ljP1000_P1500-HB-pnp-win64-ru.exe`** — получите его
  самостоятельно с сайта поддержки HP. Он содержит проприетарную firmware
  P1006 и **не входит в репозиторий**.

`scripts/prepare.ps1` проверяет SHA256 этого конкретного файла
(`6DC51BBBD0FF3E79A97603C34BC865F73FBAF529E3F54FFCEAAFE477F1EA8A61`) и
отказывается работать с другим. Поддержка других версий или языков
установщика HP не обещается.

## Подготовка

```powershell
python -m pip install -r requirements.txt
# положить ljP1000_P1500-HB-pnp-win64-ru.exe в корень проекта, затем:
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\prepare.ps1
```

`prepare.ps1` распаковывает пакет HP в `.vendor\` (установщик не запускается),
собирает конвертеры в `bin\` через `scripts\build.ps1`, готовит firmware и
выполняет диагностику. Параметр `-SevenZip <путь>` задаёт другой 7-Zip.
Отдельная пересборка с другим компилятором:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build.ps1 -Compiler C:\путь\gcc.exe
```

Рабочие файлы (`.vendor\`, `bin\`, `state\`) создаются локально и не
публикуются. Папку проекта после настройки автозапуска не перемещайте:
ярлык содержит абсолютный путь.

## Команды

| Файл | Назначение |
| --- | --- |
| `Diagnose.cmd` | Только чтение: найти принтер по USB и показать его состояние. |
| `Print-Test.cmd` | Напечатать **одну** тестовую страницу A4 (запускать вручную). |
| `Start-Bridge.cmd` | Ручной запуск моста; после старта вызывает установщик очереди Windows. Мост работает, пока открыто окно. |
| `Enable-Autostart.cmd` | Включить фоновый запуск моста при входе пользователя. |
| `Disable-Autostart.cmd` | Удалить ярлык автозапуска этого проекта. |

## Установка очереди Windows

1. Запустить `Start-Bridge.cmd` и оставить окно открытым.
2. Мост вызывает `scripts\install-printer.ps1`, который через системный
   `Add-Printer -IppURL` создаёт очередь **`HP LaserJet P1006 (ARM bridge)`**
   с драйвером Microsoft IPP Class Driver. Принтер по умолчанию не меняется.
3. Если Windows отказывает в доступе (`0x80070005`), оставить мост работающим
   и выполнить установщик в PowerShell, запущенном от имени администратора:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install-printer.ps1
```

Удаление очереди: `Remove-Printer -Name 'HP LaserJet P1006 (ARM bridge)'`.

## Печать из приложений

- Мост должен работать (вручную или через автозапуск), иначе приложение
  сообщит, что не может подключиться к принтеру.
- Выбрать `HP LaserJet P1006 (ARM bridge)` в обычном окне печати (Ctrl+P).
- **Chrome:** если принтера нет в коротком списке, нажать «Ещё…» / «See more»
  и выбрать его в полном списке.
- **Для одной пробной страницы** указать «Страницы: 1» и одну копию.
  «Копии: 1» само по себе означает одну копию *всего* документа.
- Ничего не печатается автоматически: ни при запуске моста, ни при автозапуске.

Прямая печать без очереди Windows:

```powershell
python -X utf8 -m p1006 print "C:\путь\документ.pdf"
python -X utf8 -m p1006 print "C:\путь\документ.pdf" --output state\document.xqx  # без USB
```

Остановить задание, уже переданное в принтер, можно только выключением
питания принтера; при следующем задании firmware загрузится снова.
Незавершённые задания после перезапуска моста повторно не отправляются.

## Автозапуск

`Enable-Autostart.cmd` (из обычной сессии, права администратора не нужны)
создаёт ярлык `HP P1006 Bridge.lnk` в папке «Автозагрузка» текущего
пользователя. При входе в Windows мост запускается в фоне через `pythonw.exe`,
без окна; очередь заново не устанавливается. Если мост уже работает, он не
перезапускается. Проверка без изменений:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\configure-autostart.ps1 -Action Status
```

Это запуск при входе пользователя, а не служба Windows: до входа и после
аварийного завершения мост сам не запускается.

## Проверки без принтера

```powershell
python -X utf8 scripts\check.py
```

Требует выполненного `prepare.ps1` (нужны `bin\` и `.vendor\`). Тесты не
отправляют данные в USB: проверяются преобразование документов, рендеринг PDF
средствами Windows, XQX/JBIG с обратным декодированием, HTTP/IPP на loopback,
фоновый запуск. Отчёт сохраняется в `state\verification.json`.

## Ограничения

- Только USB и только HP LaserJet P1006 (`03f0:3e17`).
- A4, односторонняя чёрно-белая печать; 300×300, 600×600 и 1200×600 dpi на
  входе, поток принтера 1200×600. Неподдерживаемые параметры IPP отклоняются.
- До 100 исходных страниц, 99 копий, 1000 страниц с учётом копий.
- Нет duplex, произвольных форматов, уровня тонера и подтверждения выхода
  каждой страницы.
- Не проверены: физическая печать из Chrome, автозапуск после реального
  повторного входа в Windows, замятие/отсутствие бумаги, переподключение USB.
